# 通用PYNQ技能的提炼

技能包保留三项提示词工作流：DMA与缓存生命周期诊断、黄金参考逐字段比对、性能与资源分析。适用范围、输入、使用方法、失效条件和经验来源集中在[技能说明](../skill/readme.md)。

提炼从具体误判开始：等待被人工停止后，日志不能直接证明DMA超时；数组对象仍存在，也不能保证底层缓冲未被下一帧覆盖；相同算法的两种模式可能使用不同接受集合；并行阶段的耗时不能简单相加；模块OOC报告不等于整板实现。将这些问题转换成输入资料和决策顺序，便可用于其他采集、滤波、信号处理与控制工程。

入口不预设板型、固定寄存器地址、相机分辨率或数值容限。使用者提供实际HWH/BD、驱动、日志、参考数据和比较合同；智能体先确认事实，再定位问题，按已有授权完成允许的测试，并保留失败输入。

导出测试验证技能文件可离开本仓库使用、相对引用可读、缺件拒绝以及输出防覆盖。测试命令为`python -B sim/tools/test_build_skill.py`。这组测试针对交付和安装；DMA行为、精度和吞吐需要在目标工程中另行验证。旧文件工具的测试数量不作为当前工作流的验证结果。

现有技能由本项目开发经验整理；PYNQ相关操作仍按目标环境的驱动和工具接口执行，不自动连接、重置或加载板卡。

独立案例试用覆盖DMA等待后人工中断、仅有OOC报告、参考点记录错序三种情形。技能分别要求补齐驱动与状态证据、整板实现与实测时间线、遵守原顺序合同；三个案例的判断与输入资料一致。
