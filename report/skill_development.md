# 工程校验工具

自主选题指南第3.3.5.2节要求技能写明适用范围、用法、效果、失效条件和经验来源。本项目从归档遗漏和驱动混用两类问题中提炼工程校验工具，供其他PYNQ工程复制、部署和交接时使用。

| 工具 | 输入 | 输出 |
|---|---|---|
| Bundle Checker | 工程根目录与文件清单 | 文件完整性、缺失、额外文件和摘要检查结果 |
| Overlay Release Checker | 固件manifest与运行程序目录 | bit/HWH、受保护程序及路径检查结果 |

两个工具均为只读程序，使用Python标准库，不依赖在线板卡。接口、调用示例和错误类别见[使用说明](../skill/readme.md)。

通用化组织参考OpenAI Skill Creator、AMD Ross任务型技能及PYNQ官方接口文档：共同输入由任务合同表达，执行流程按文件配套、DMA诊断、黄金参考比对、性能分析分别选取。前两份校验脚本是本包可执行工具；DMA与分析提示词是可复用指引，各工程仍需使用对应驱动和测试验证。来源和采用理由集中写在技能说明中，不复制厂商技能为自研产物。

技能包提供标准Agent入口，已在独立工程目录中验证原生发现。检查器保存报告使用`--output`，测试脚本使用`--report`；正确配套返回0，修改驱动的副本返回1并指出具体文件。

提炼过程：脚本从驱动混用问题中抽取文件清单和运行程序目录两个输入，原有代码已不依赖算法或板型。将说明改为独立工程用法后，以图像滤波、信号采集工程完成4项复用测试；又以FFT、控制和计数工程核对提示词、迁移和失败处理。

离线工具回归：Overlay检查27项，26项通过、1项环境跳过；整包检查28项，25项通过、3项环境跳过；4项复用测试通过。另完成3轮33个CLI案例，结果见[技能测试](../sim/results/skill_regression.json)。补测发现并修复清单异常退出、重复键误接受、中文控制台输出和BOM兼容问题，文件读取采用有界分块。

测试覆盖正确文件、内容损坏、文件缺失、路径越界、重复清单和软件绑定变化；结果及对应运行范围见[验证汇总](release_validation.json)。检查流程保留原输入和错误日志，输出可用于自动化检查与人工定位。

文件清单用于识别工程内容，数字签名用于确认发布者，两者职责分开；实际设备状态由运行程序读取寄存器确认。

仓库提供标准库打包入口`sim/tools/build_skill.py`，按固定清单导出原生技能目录并保留标准`SKILL.md`。导出测试覆盖重复构建一致、旧包防覆盖、缺失或损坏输入拒绝、源目录保护，以及中文和空格路径下解压独立运行。四组回归合计65项：61项通过、4项因链接创建权限跳过，记录见[安装包验证](../sim/results/skill_package.json)。
