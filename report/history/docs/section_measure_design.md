# PL 截面测量：设计

目标：把 `runtime/r33/profile_live.py` 的 `measure_frame`（ARM 上 Python，每帧排序、中位数、逐段拟合）搬到 PL。ARM 每帧只读约 20 个寄存器，截面画点仍由 ARM 用 NumPy 投影。

- 模块：`rtl/section_measure.sv`，PFO3 AXI 窗口 0x700–0x7FF。
- 接口：与 `r41_measure` 相同，只读监听 `geo_out_record`，按包提交 / 丢弃。
- 参考模型：`model/section_measure_model.py`。RTL 与模型逐位一致；模型与浮点版的对比见 `scripts/section_model_compare.py`。

## 为什么要存点

第一版是纯流式设计：按行顺序处理，噪声用截断均值，阈值沿用上一帧，偏移用均值。在 182 帧实拍上与浮点版差得很远：台阶差 p95 为 82 mm，噪声只有浮点版的 0.17 倍。

逐项替换后的结果（`tmp/section_variants.py`）：

| 排序 | 中位数噪声 | 本帧阈值 | 偏移 | 台阶差 p95 | 段数一致 |
| --- | --- | --- | --- | --- | --- |
| 否 | 否 | 否 | 均值 | 82 mm | 46/182 |
| 否 | 是 | 否 | 均值 | 44 mm | 136/182 |
| 否 | 是 | 是 | 均值 | 18 mm | 162/182 |
| 是 | 是 | 是 | 均值 | 1.7 mm | 182/182 |
| 是 | 是 | 是 | **中位数** | **0.0002 mm** | 182/182 |

所以 PL 版要先把窗口内的点全部存下来，再按 s 排序，噪声、点距、偏移都用精确中位数。

## 流程

1. **取点**：flags 有效且等级符合，相机 Z 落在 `[z_min, z_max]` 内。自动深度窗口由软件写入。
2. **投影**：q = p − o（Q16），s = q·e_s，h = q·e_h（e 为 Q24），6 路乘法流水，每拍一点，写入点存储（1024 × 64 位，2 个 RAMB36）。超出 1024 点只计数。
3. **包提交后**，顺序状态机依次执行：
   1. 插入排序：按 s 稳定排序。实拍数据近似有序，约 3n 拍。
   2. 点距 = 相邻 Δs 的中位数；噪声 = 二阶差分绝对值的中位数 × 1.4826/√6。
   3. 中值 3 平滑后分段：Δs > max(break, 4×点距) 或 |Δm| > max(jump, 5×噪声) 处断开；段长 ≥ min_points 才入表，最多 16 段。
   4. 每段做最小二乘，剔除 3σ 外的点（下限 0.02 mm）后重拟合一次，得到斜率 a（Q24）、截距、均方根，以及 1/√(1+a²)。
   5. 段偏移 = 该段各点相对另一段直线的垂直残差的中位数 × 1/√(1+a²)。
   6. 参考段、主台阶、相邻台阶表、间隙（宽度、两端、深度）按 `profile_live` 的规则计算，level = max(level, 3×噪声)。
4. **精确中位数**：对 32 位值逐位二分，每位扫一遍数据并计数。偶数个时同时求两个中间值，取平均（向下取整），与 numpy 一致。

## 与浮点版的差异（182 帧实拍，`evidence/section_model_compare.json`）

| 指标 | 结果 |
| --- | --- |
| 窗口内点数 | 182/182 相同 |
| 段数 | 182/182 相同 |
| 主台阶有效 / 无效 | 182/182 一致 |
| 主台阶差（94 帧双方有效） | 中位 0.00004 mm，最大 0.00025 mm；全部 ≤ 噪声的 1/2 |
| 间隙有效 / 无效 | 182/182 一致；宽度差最大 0.00002 mm |
| 噪声比 | 中位 1.000，最大 1.0005 |

尚未实现、由软件补充的：

- 间隙"采集空洞"判定（需要点所在行和行摘要）；
- 台阶夹角（可由两段斜率算出）。

## 运算单元（顺序复用）

- 扫描流水：点存储读（2 拍）→ s − s0 → a × (s − s0)（DSP 流水）→ 残差 → 计数、求最小或累加。每拍一点。
- 乘法器：40 × 68 位有符号，移位相加，约 40 拍。
- 除法器：112 / 80 位，商饱和为 64 位，64 拍。
- 开方器：64 位，32 拍。
- 最坏情况（1024 点、16 段）估计约 25 万拍，即 2.5 ms，远小于帧周期。求解期间到达的点丢弃并计数。

| 08 0C 10 | 原点 X Y Z（Q16） |
| 14 18 1C | e_s X Y Z（Q24） |
| 20 24 28 | e_h X Y Z（Q24） |
| 2C 30 | z_min z_max（Q16） |

| 50 | 已提交包数 |

| 58 | [4:0] 段数，[31] 段溢出 |
| 5C | 状态：b0 主台阶有效，b1 间隙有效，b2 深度有效，b3 有段，[11:8] 参考段，[15:12] 台阶段，[19:16] 相邻台阶数 |
| 60 64 68 | 主台阶、间隙宽度、间隙深度（Q16） |
