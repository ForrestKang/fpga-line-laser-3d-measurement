# HDMI 界面规范：工业视觉风

系统名：**智能线激光三维测量系统**。三页，1280×720，按键直接选页。用户已于 2026-10-30 确认静态稿（`ui_mockups/*.png`）。

## 代码

| 文件 | 作用 |
| --- | --- |
| `runtime/r33/ui_theme.py` | 配色、字体、高度色带、1-2-5 刻度 |
| `runtime/r33/ui_pages.py` | `PageRenderer` 画整页；`PageCompositor` 限速重画并逐帧贴相机图；`Glyphs` 文字掩膜缓存 |
| `runtime/r33/page_state.py` | 每帧数据 → 三页内容（趋势、截面视图、分带直径、设备状态、提示） |
| `runtime/r33/live.py` | `--layout pages`（默认）接入；`--ui-refresh-s` 设重画周期（默认 1 s） |
| `runtime/r33/pl_view.py` | `set_window` 切页时移动 FPGA 点云窗口 |
| `scripts/build_page_fonts.py` | 按页面源码里出现的字符生成字体子集 |
| `scripts/render_ui_mockups.py` | 用归档真实数据出静态稿 |
| `scripts/replay_pages.py` | 真实帧走实时路径（PageState → 合成器）出图 |

## 结构

- 顶栏 36 px：系统名，右侧三个页签（实时 BTN1 / 截面 BTN2 / 扫描 BTN3），当前页填强调色。
- 面板：实心标题栏 22 px，左标题，右侧灰色附加信息。无圆角、无阴影。
- 底栏 26 px：设备指示（相机、FPGA、激光、电机），中间最多一条提示（红=故障，黄=注意），右侧帧号、帧率、延迟、时钟。

## 三页

| 页 | 内容 |
| --- | --- |
| 实时 | 处理流水线（相机采集 → 条纹提取 → 坐标解算 → 点云显示，前两段 FPGA 标记）；相机画面 + 条纹中心；逐行亮度 / 宽度 / 饱和；FPGA 点云窗口 (823,131)；单帧处理、点数、曝光三条趋势；采集质量 |
| 截面 | 截面轮廓 + 参考面公差带 + 台阶标注；测量表（主台阶、其他台阶、间隙、参考面残差、噪声，名义 / 公差 / 判定）；台阶趋势（超量程点截顶标红）；相机缩略图 + 测量窗口；5 项采集质量条；参考面残差直方图 |
| 扫描 | FPGA 点云窗口 (9,65)；角度覆盖表盘；进度（已采、用时、剩余、点数）；直径-高度曲线；分带直径表；扫描记录（状态、开始、文件、转台、条纹、转轴） |

## 数据来源（板上）

- 条纹提取时间 = 帧头 `processing_cycles` ÷ 100 MHz（PFO3 前端 aclk）。
- 单帧处理 = ARM 端 PFO3 调用墙钟时间；曝光 = PL 自动曝光行数（未开启时改画条纹提取时间）。
- 截面：`measure_frame` + `ProfileTracker`；主台阶取跟踪器判定值，标注取本帧值。
- 分带直径：扫描接受帧的物体坐标点，沿转轴每 4 mm（或 1-2-5 步距）一带，带宽 ±1 mm，至少 20 点。
- 设备：激光由用户手动控制，固定显示"手动"；电机按扫描状态 / 授权 / 12V 声明显示。

## 刷新

- 整页由 Pillow 在主循环重画，周期 `--ui-refresh-s`（默认 1 s）；文字走掩膜缓存，同一字符串只栅格化一次。
- 实时页的相机区每帧用 NumPy 贴入（640×408）。
- 截面、扫描页两次重画之间直接复用只读整页。
- 点云窗口内软件只画面板底色，PL 的 0 号色透明。
