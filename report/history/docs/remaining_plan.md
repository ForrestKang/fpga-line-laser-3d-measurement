## 1. 截面测量收尾（纯 PC）

1. **修时序**
   - 最差路径是分段：`g_hjm` → 中值 3 → 求差 → 断段判断 → 写段表，21 级逻辑。
   - 改成两级：第一级算出 m_j，并把 s_j、s_{j−1}、h 等寄存；第二级判断断段并写表。末尾的冲刷状态同步顺延一拍。
   - 修完后看下一批最差路径，预计在残差级（3 输入 66 位加法加饱和）和乘法器。按需再切一级。
2. **乘法器减 LUT**：`sm_mul` 现在是 1,175 LUT 加 8 DSP，40×68 位的部分积有一部分落在 LUT 里。
   - 方案 A：拆成 3 段 × 2 段的 DSP 部分积，加一个移位累加，多花几拍。
   - 方案 B：按用途收窄位宽。
   - 两种都不改结果。
3. **门槛**
   - 单独构建 WNS ≥ +0.5 ns，给整合留余量；LUT ≤ 7k。
   - 195 包逐位一致（`scripts/section_rtl_verify.py`）。
   - ruff 检查脚本。
