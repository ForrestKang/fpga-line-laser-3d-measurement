# 转台扫描：预览级视角

日期：2026-10-30。

**修改位置**：`runtime_scan/`，基于 Codex 的 `btn0_full_scan_20261030/runtime`，那份没有改动。板上对应 `btn0_full_scan_20261030_01/runtime_preview` 与 `release_preview`，服务为 `scan3d-btn0-preview-demo`，仅在本次开机内有效。

## 原因

上一圈 166 个视角被跳过，统计如下：

| 项目 | 被跳过的视角 |
| --- | --- |
| 预览级点数 | 131–210 |
| PL 判定预览可用 | 全部可用 |
| 饱和像素中位数 | 90（上限 360） |
| 测量级行数 | 中位 87.5，未达到 PL 测量门槛 120 行 |

物体在画面中多数角度只覆盖约 90 行条纹。

## 修改

- 视角在最后一次重试时，若该帧 PL 预览可用、且预览点数 ≥ `--scan-preview-min-points`（默认 60），记为 `preview` 视角并接收。
- 测量级仍然优先；PL 门槛不改。
- 点云第 4 列：1 = 测量，0 = 预览。
- 状态统计分开记录 `measured_views` / `preview_views` / `skipped_views`：
  - `data_complete` 只按测量级判定；
  - 新增 `coverage_complete`，表示无跳过视角。
