# 尺寸精度结论（2026-10-31）

系统：PYNQ-Z2 PL 实时激光中心提取与几何解算，转台步进扫描（200 视角，3547 步/圈，5 RPM），开机固化版本（`/boot` → firmware `deploy_timing`，runtime `release_final`）。

## 标定

- 相机内参：f = 1025 px，重投影 0.35 px。
- 激光平面：棋盘格 4 个姿态，留出姿态误差 0.11–0.22 mm。
- 尺寸与转轴：用 T02 一次转台扫描（200 视角）拟合，偶数视角拟合、奇数视角检查。
  - 激光平面偏移乘以 0.890 后再乘以 0.996；
  - 转轴修正 9.2 mm、7.9°。
- 角度系数：棋盘格实测，实际角度 = 0.902 × 指令角度，即 3547 步/圈。

## 以卡尺实测为真值的精度

| 物体 | 位置 | 项目 | 卡尺 | 扫描 | 误差 |

| | | 中段直径 | 30.0 | 29.90 | −0.10 |

| | | 段高 | 16.0 / 16.0 | 16.0 / 16.0 | 0 |
| 花瓶 C1（独立物体，未参与标定） | — | 颈部最小直径 | 16.5 | 16.23–16.55 | −0.27…+0.05 |

- 圆度：T02 为 0.21 mm；花瓶的设计纹理圆度为 1.19 mm，扫描结果为 1.11 mm。
- 花瓶与 STL 设计相比，按角度均匀取样平均偏小约 0.7 mm。卡尺证实这是打印件本身比设计小：颈部设计约 17.2 mm，实物 16.5 mm。这不是测量误差。
- 花瓶底座卡尺读数为 36.0 mm。底座外缘只有 1.3 mm 高，扫描最下层混入了底座顶面和转台，不用于比较。
