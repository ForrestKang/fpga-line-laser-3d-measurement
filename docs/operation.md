# 操作与数据

## 三页与按键

| 按键 | 界面/动作 | 页面内容 |
|---|---|---|
| BTN1 | 实时观测 | 相机图像、光条与当前三维截面 |
| BTN2 | 截面测量 | 截面、主台阶、质量和趋势 |
| BTN3 | 整圈扫描 | 累积点云、角度进度、尺寸状态 |
| BTN0 | 开始/停止请求 | 由扫描状态机和现场运动准入决定是否执行 |

按键不会替代固件、标定或运动的准入检查。具体运行参数以真实入口`--help`为准，见[部署说明](build_and_deploy.md)。

## 数据层次

- **Raw**：相机灰度帧，用于完整记录和诊断。
- **primary / PFO3**：真实PL输出流、最终观测、质量、分支和来源。
- **measurement XYZ**：通过正式测量判据的三维点。
- **preview XYZ**：独立预览点，不进入正式尺寸集合。
- **metadata / trace**：帧号、epoch、参数身份、角度、后端、错误和各阶段时间。
- **cloud / features**：扫描级点云及分析导出；有效状态与单位随结果记录。

实际文件布局由[存储实现](../src/ps/r33/storage.py)及运行配置决定；历史示例见[板端证据说明](../board/readme.md)。不要把历史量化点云还原件当成完整原始采集。

正常帧质量读取PL行摘要和接受决定位。需要对照Raw饱和计数时显式启用`--diagnostic-raw-quality`，结果标记为诊断，不改变measurement或preview接受判据。手动初始化曝光使用`--exposure-rows`的原有probe流程，与此开关独立。

严格存储读回根据primary头部显式选择图像观测或几何观测协议，支持水平双像素模式；身份、CRC、记录完整性及源绑定均保留。新软件的实际回归状态见[验证汇总](../report/release_validation.json)。

## 完成状态

计算完成、显示完成、入队和持久化是不同事件。只有关联数据和索引同步后才能确认持久化；取消时先停止新任务，保留已接受范围、错误和未完成范围，不能直接清空队列并宣布全部完成。

## 展示件

主要展示台阶块、阶梯圆柱和波纹花瓶。台阶相邻高差为2/3/5mm，阶梯圆柱各段直径为40/30/20mm。标称尺寸用于描述测试件；实际结果、单位和标定使用关系按[验证文档](validation.md)逐项对应。STL与模拟真值不输入正常提取或拟合路径。
