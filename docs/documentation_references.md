# 文档组织参考

本次阅读以下项目的官方文档，借鉴信息结构，不复制其实现或测试结论：

- [AMD PYNQ](https://github.com/Xilinx/PYNQ/blob/master/README.md)：先解释用途和能力，再提供Quick Start、源码、板卡overlay、支持及许可入口。
- [Corundum](https://github.com/corundum/corundum/blob/master/README.md)：在系统介绍后给出框图、模块职责、软件和仿真入口。
- [OpenTitan Getting Started](https://opentitan.org/book/doc/getting_started/index.html)及[目录规范](https://opentitan.org/book/doc/contributing/directory_structure.html)：区分模拟、FPGA和验证工作流，把硬件、软件、工具和文档分别导航。

本项目据此采用“作品效果—架构—快速开始—构建/使用—验证—已知问题—贡献/许可”的阅读顺序。项目数据和模块描述均来自本仓库，不沿用上述工程的性能或验证结论。
