# 实现、性能与测量结果怎么读

## 整板资源

当前归档实现为双方向通道、100MHz系统、125MHz视频域。LUT73.52%、FF47.84%、BRAM78.93%、DSP60.91%，布线后WNS+0.230ns、WHS+0.011ns、CDC Critical0。原报告路径见[验证表](validation.md)。

## 速度分开报告

| 指标 | 应统计的事件 |
|---|---|
| PL处理能力 | 对应硬件输入/输出与cycle，注明100MHz换算 |
| 有效三维 | 产生新有效XYZ的帧，不是仅接到Raw |
| 新模型显示 | 新观测实际进入画面并确认，不累计重复心跳 |
| 持久化 | 数据与索引完成同步后的确认 |
| 全部墙钟 | 包含启动、排空、分析、导出和退出 |

技术报告摘要中的约26.5帧/s描述PL逐帧图像处理，不能当作转台扫描、HDMI和SD完整保存均达到同一速度。约200视角、2.5分钟及约6.6万点属于报告记录的扫描实例。本轮仓库整理没有重跑板端速度。

对照时固定输入、软件、库、bit/HWH、标定和配置，给出完整5秒窗口、p50/p95/p99、CPU/内存/CMA、队列及画面年龄。并行阶段墙钟不能简单相加为整链耗时。

## 精度分开报告

二维条纹中心误差使用像素；Q12是编码的小数位，不代表真实测量精度。三维尺寸使用毫米，需对应独立参考、标定来源、部位和可见性。当前报告中的模拟、历史回放和实物结果分别保留，不将它们合并成全系统统一精度。

同一个测试件若参与标定方案选择，其尺寸对照作为复核；另用独立件确认泛化。背景到物体的距离不等于相邻台面的高差。现有完整边界和未通过项见[验证](validation.md)与[已知问题](known_issues.md)。
