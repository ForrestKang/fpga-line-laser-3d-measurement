# 常见问题

| 现象 | 先检查 | 不应直接做 |
|---|---|---|
| 源码恢复报输出已存在 | 换一个全新输出目录 | 覆盖原工程 |
| 找不到字体/大小写不同 | 用source_map恢复后运行，检查依赖 | 直接重命名冻结文件 |
| 找不到Vivado或器件 | Vivado2025.2、XC7Z020器件支持、PATH | 静默升级IP继续比较 |
| 发布检查器返回FAIL | 看bit/HWH和每项runtime guard结果 | 只改摘要绕过拒绝 |
| 相机ID/PCLK异常 | 供电、接线、启动标识、当前硬件所有者和诊断 | 反复加载并自动转动 |
| 加载后ABI不符 | 实际MMIO、bit/HWH与驱动合同 | 根据磁盘文件存在推断已加载 |
| HDMI黑屏/页面滞后 | 视频配置、VDMA、缓冲分配、重画与确认时间 | 用重复ACK冒充新画面 |
| 可用内存/CMA低 | 区分普通内存和连续分配，记录失败请求 | 只看总空闲就认定可运行 |
| 保存突然停顿 | fsync时间线、队列帧数/字节、剩余空间 | 关闭同步后宣称持久化提速 |
| 模型环带/错层 | 光平面、转轴、实际角度、单位与参数来源 | 直接按CAD补点或用被测件调准后自证 |
| 台阶读数异常大 | 物体区域、参考面、相邻级差与背景分离 | 把背景距离当台阶高差 |

提交问题时附：源码commit、库/固件身份、实际配置、完整命令、复现输入范围、原错误日志、预期与实际。不要上传密码、私钥或可转移的运动授权。
