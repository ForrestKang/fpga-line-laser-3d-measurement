# 常见问题与处理方法

| 现象 | 处理方法 |
|---|---|
| 恢复目录已存在 | 为源码恢复指定一个新的输出目录，保留已有工程 |
| 字体或文件大小写不匹配 | 通过source_map恢复文件名，按依赖清单配置环境 |
| 找不到Vivado或器件 | 检查Vivado 2025.2、XC7Z020器件支持和PATH |
| 固件配套检查报错 | 根据检查结果核对bit、HWH、运行程序及原生库架构 |
| 相机ID或PCLK异常 | 检查供电、接线、复位状态和相机诊断寄存器 |
| 加载后ABI不匹配 | 核对实际MMIO返回值、固件和驱动配置 |
| HDMI黑屏或页面延迟 | 检查视频时钟、VDMA、显示缓冲和提交确认时间 |
| 普通内存或CMA不足 | 分别检查可用内存和连续内存，记录分配请求及结果 |
| 保存出现长时间停顿 | 核对同步耗时、队列帧数和字节数、磁盘余量 |
| 点云出现环带或错层 | 核对光平面、转轴、实际转角、单位及参数来源，使用同一批数据复算定位 |
| 台阶读数异常大 | 检查物体区域、参考台面与背景分离，按相邻台面计算高差 |

定位问题时记录源码提交、固件和库信息、运行配置、完整命令、输入及错误日志。相机、激光和转台的位置改变后，应复核对应几何参数。
